This project is a yearlong yearlong agile scrum team for my `SWE4901-4902 - Software Engineering Capstone I & II` course where we are creating a web application that is a one stop shop for new graduates looking for full time positions or students looking for internships. The application scraps for job listings and creates a progress kanban style board for students to visualize their progress in the job search process. The application also has a resume feature that allows students to do a comparison between their resume and each individual job discription to look for discrpancies, and what the user should add. The application also has a SSO feature that allows students to log in with their school credentials. The application is built with React for the frontend, ASP.NET Core for the backend, C# for the backend logic, MySQL for the database, GitLab for version control and CI/CD, and web scraping for job listings.
