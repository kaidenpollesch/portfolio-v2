This app was designed for Green Lake Conference Center (GLCC) to help visitors navigate the 900-acre lakeside campus. The app is built using Expo and React Native, with TypeScript for type safety. It utilizes MapLibre and OpenStreetMap for map rendering, and Protomaps for offline map tiles which allows the app to function fully offline, which was important with the confrence center being out in the woods. The A* pathfinding algorithm is implemented to provide efficient route calculations between points of interest on the campus.
