What was Completed:
- **Proxmox** was installed as a Type 1 bare metal hypervisor on an old 2017 MacBook Pro. 
- **AdGuard** was used for network wide adblocking, DNS rewrites, so I have custom domains for my different services, and to protect the network by blocking anything malicious. 
- **Vaultwarden** (Open Source Bitwarden) was used to host my own password manager so large tech doesn't have my passwords. 
- **OpenMediaVault** was used to host a local NAS for file storage and backups. 
- **Wireguard** was used to create a secure VPN connection to my home network when I am away from home.
